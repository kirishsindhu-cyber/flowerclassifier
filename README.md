# Iris Flower Classifier (ANN)
Feed-forward neural network (TensorFlow/Keras) that classifies Iris flowers, served with Streamlit.
- `Flower_Classifier.ipynb` - data exploration, training, evaluation
- `app.py` - web app; `iris_model.keras` + `scaler.pkl` - saved model
Run: `pip install -r requirements.txt` then `streamlit run app.py`
